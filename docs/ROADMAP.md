# Roadmap

## Phase 1 — Foundation

- Set up the Next.js portfolio structure
- Build the public-facing portfolio pages
- Add reusable components and navigation
- Establish design patterns and content layout

## Phase 2 — Content and Data

- Add MongoDB-backed project and article schemas
- Connect portfolio pages to real content sources
- Validate models and content queries
- Add admin support for managing content

## Phase 3 — Admin Dashboard

- Build the authenticated dashboard UI
- Add dashboard API for aggregated stats
- Display recent content and activity
- Keep the UI stable while replacing mock data

## Phase 4 — Experience and Quality

- Improve validation and error states
- Harden security and auth flow
- Standardize logging and environment config
- Audit the codebase for stale or unused files

## Phase 5 — Production Readiness

- Test the deploy pipeline
- Verify production environment variables
- Confirm admin access and MongoDB connectivity
- Document architecture, setup, and deployment

## Backlog

- Add automated tests for API routes
- Add stronger admin CRUD flows for articles and projects
- Improve performance and image optimization
- Expand analytics and reporting where needed
- Review stale project files for future cleanup
